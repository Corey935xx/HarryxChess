# HarryxChess

A polished browser chess game with single-player AI and local two-player modes.

## Run locally

Open `index.html` in a modern browser. The chess rules library is loaded from jsDelivr, so an internet connection is required on first load.

## Features

- Single-player chess against a built-in minimax AI with three difficulty levels
- Two-player pass-and-play on one device
- Full legal move validation, check/checkmate, stalemate, repetition and draw detection
- Castling, en passant and promotion
- Move history, captured pieces, undo, board flip and restart
- Responsive layout for desktop, tablet and mobile

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. The game will be served from `index.html`.
